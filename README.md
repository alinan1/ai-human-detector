# AI vs Human Text Detector

## Project Summary

This project uses machine learning to classify whether a piece of text was written by a human or generated by artificial intelligence. As AI-generated creations advance it is becoming increasingly difficult to distinguish between human and ai-generated writing, which raises concerns in areas such as education and media.

To address this problem, we analyzed linguistic features such as word count, sentence length, vocabulary diversity, punctuation frequency, average word length, stopword ratio, and paragraph count. These features were extracted from raw text data and used to train machine learning models including Logistic Regression, Decision Tree, and Random Forest.

The project follows a complete data pipeline which includes
1. data cleaning
2. feature extraction
3. database storage
4. visualization
5. model training + custom feature where users can input their own text into the command-line and will predict whether it is human-written or AI-generated**

## How To SETUP project before running

### 1. Clone the Repository

```bash
git clone https://github.com/alinan1/human-ai-detector.git
cd human-ai-detector
```

### 2. Create a Virtual Environment

```bash
python3 -m venv venv
```

### 3. Activate the Virtual Environment

**Mac / Linux:**
```bash
source venv/bin/activate
```

**Windows:**
```bash
venv\Scripts\activate
```

### 4. Install Required Packages

```bash
pip install pandas numpy scikit-learn matplotlib
```

---

## How to RUN the Project

### Step 1: Set Up the Database

```bash
python src/db-setup.py
```

### Step 2: Extract Features

```bash
python src/dataextract.py
```

### Step 3: Train Models and Run Predictions

```bash
python src/model.py
```
1. Once the models finish training you will be automatically prompted in the terminal to enter your own text:
2. Simply paste or type any text (we recommend)
4. The system will extract the same linguistic features used during training, scale them, and run them through the best-performing Random Forest model. 
3. It will then print wether text was AI-generated or Human written

### Step 4: Create Visuals 
```bash
python src/visual.py
```
